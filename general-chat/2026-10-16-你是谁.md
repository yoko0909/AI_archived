如何将仓库路径改为允许写入的目录呢？

## Codex

可以按下面步骤操作。

1. 在 PowerShell 中移动仓库：

```powershell
Move-Item `
  -LiteralPath "C:\Users\yongkang.guo\Documents\AI_archived" `
  -Destination "C:\Users\yongkang.guo\Documents\Codex\AI_archived"
```

2. 打开配置文件：

```powershell
notepad "C:\Users\yongkang.guo\.codex\ai-conversation-archive\config.yaml"
```

将：

```yaml
path: C:/Users/yongkang.guo/Documents/AI_archived
```

改为：

```yaml
path: C:/Users/yongkang.guo/Documents/Codex/AI_archived
```

3. 验证仓库：

```powershell
git -C "C:\Users\yongkang.guo\Documents\Codex\AI_archived" remote get-url origin
```

输出应为：

```text
https://github.com/yoko0909/AI_archived.git
```

然后再次调用归档技能即可。
